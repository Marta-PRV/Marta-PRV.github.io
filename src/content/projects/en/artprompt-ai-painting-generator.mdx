## What it is

A project exploring the meeting point of **artificial intelligence and artistic creativity**: finding out how far a model can learn painting styles and apply them to new artworks.

The user picks an **artist**, writes a **prompt** (a description) and gets an image generated in that style, next to two real works by the same artist for comparison.

## What I did

- Built the **dataset by hand** with works from 5 artists.
- Implemented a **neural network** that classifies each artist's style.
- Integrated **Stable Diffusion** to generate the images.
- Built the **interactive interface** with widgets inside the notebook (artist dropdown and text box).

## How it works

1. **Image preparation.** Every image is resized to 512×512, converted to a tensor and normalised between -1 and 1 so training is stable.
2. **Style classification.** A simple neural network (fully connected layers) learns to tell the artists apart. It is trained with the Adam optimiser, cross-entropy loss and a scheduler that lowers the learning rate when the loss stops improving.
3. **Generation.** The user's prompt is combined with the chosen artist's style and sent to Stable Diffusion (`stable-diffusion-v1-4`). The result is shown next to reference images from the dataset.
